# Publish the scientific record by default

All published research and governance history is readable and downloadable without authentication so humans and agents can build on the same evidence. Every Problem Version, Contribution Version, and Verification Report receives a permanent version-specific URL and standard citation export; DOI minting is deferred until stable platform citations prove insufficient. Submitted Challenge and Problem Proposals, reviews, requested changes, approvals, and rejections are public and timestamped; only drafts and quarantined abuse remain private. Account deletion deactivates access and removes private profile data, but published scientific and governance records retain stable pseudonymous attribution where legally permitted; retraction marks history rather than erasing it. Authentication is required only for participation, so the current starter behavior that protects nearly every route must not apply to the Public Scientific Record.
