# Model Problems as a graph

Problems form a dependency graph rather than a parent-child tree because one result may advance several scientific Problems. Typed depends-on, supports, and contradicts Problem Links reuse the same evidence without duplication, while a linked Solution informs but never automatically solves a parent whose own acceptance criteria remain authoritative. Anyone may propose a separately governed fork with an explicit diff when assumptions, scope, criteria, or direction diverge; exact duplicates are rejected. Contributions form their own typed citation graph—builds on, supports, contradicts, and reproduces—so later work cannot erase its lineage. Practical Applications separately explain how Problems may enable technology or contribute to real-world Challenges.
