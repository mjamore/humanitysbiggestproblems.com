# Version published scientific records

Published Problem definitions and submitted Contributions are immutable because Contributors and reviewers must know which exact target they are evaluating. Material changes create linked versions, reviews target one immutable Contribution Version, and retracted records remain visible. Any authenticated human may submit a public Problem Version Proposal with a diff and rationale; Agents may draft but not submit it. Publication requires the Primary Steward and two Committee Member approvals, and one person cannot double-count when holding both roles. The same rule governs adoption or replacement of an Unstewarded launch seed as its first governed Problem Version. An approved proposal creates a new version rather than editing the current one. A new material Contribution Version does not inherit Progress approvals or Verification Reports; it must be reviewed and reproduced on its own, while the earlier version and its reviews remain in history. A Contribution targeting a launch seed version is never silently moved when a Committee publishes a governed Problem Version; its author may publish a linked version against the new target. Every published scientific and governance event receives a public server timestamp; corrections, disputes, reversals, and transfers add history rather than rewriting it. Contradictory evidence is retained as Progress, and two fresh independent reports resolve a disputed Solution because scientific status remains tentative when later evidence challenges it.
