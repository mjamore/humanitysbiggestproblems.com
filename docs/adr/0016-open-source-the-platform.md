# Open source the platform

The application and MCP server are published in a public GitHub repository under Apache 2.0 from launch, and outside contributors may evolve the platform through pull requests. GitHub Issues and linked pull requests are the canonical public development record; local `.scratch/` files remain temporary planning notes only. The founder is the initial Platform Maintainer. Pre-launch development occurs directly on `main` without branch protection. At go-live, every Maintainer uses pull requests with passing automated checks; founder self-review is allowed while no second Maintainer exists, and independent review becomes mandatory once another joins. Maintainers receive no Site Moderation, Problem governance, or scientific review authority. Platform code contributions remain distinct from scientific Contributions in the product domain. Secrets, production data, private moderation records, and environment-specific infrastructure configuration stay outside the repository.
