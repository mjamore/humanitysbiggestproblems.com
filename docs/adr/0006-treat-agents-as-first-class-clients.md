# Treat agents as first-class clients

Human and agent access have equal product importance from launch. Every scientific capability must be designed across the human web experience, canonical JSON API, and MCP server, while public HTML and Markdown expose the same readable record. Public scientific records require no key under anonymous rate limits; authentication is reserved for participation and elevated operational limits. The JSON API begins at `/api/v1`, MCP tools use versioned schemas, and breaking machine-contract changes require a new version plus a published deprecation period. Scientific documents use structured domain fields with Markdown prose and separate versioned Research Artifacts, so the web editor and agent interfaces share one underlying representation. Parity remains role-aware: Operators may grant Agents revocable read-only or autonomous Contribution-submission scope, but only humans may vote, submit Problem Proposals, admit Committee Members, publish Verification Reports, transfer stewardship, or moderate. Onboarding uses one public Streamable HTTP MCP endpoint with browser OAuth and client-specific add-server instructions, followed by a starter prompt only after connection. Claude Custom Connectors and Codex are officially supported at launch; ChatGPT consumer support waits for approved plugin publication, while Developer mode is labeled a technical preview. No prompt, URL, or tool argument contains a long-lived secret, and untested clients are not advertised as supported.
