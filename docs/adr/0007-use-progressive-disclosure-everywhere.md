# Use progressive disclosure everywhere

Every human and agent interface follows one disclosure ladder: Challenge summary; Problem snapshot; Problem Version and Research Brief; Contribution index; then full Contributions, Verification Reports, and artifacts. A bounded Problem Context provides the current version, Seed or Research Brief, acceptance criteria, active or Suggested Directions, and links or tool calls to deeper evidence as the shared starting point. Web expands visually, Markdown follows links, JSON paginates, and MCP uses deeper tool calls. Launch search uses native full-text search and structured filters across Problems, Research Briefs, Contributions, and Sources on every interactive interface; semantic or vector search waits until the corpus and observed failures justify it. This limits visual complexity, implementation burden, and agent token cost without hiding the open scientific record; no default response dumps the entire research tree.
